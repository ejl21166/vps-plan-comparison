## 便宜的部分，和需要接受的部分

$21.99/年买到 1 核 1GB、20GB SSD、3TB 流量、1Gbps 端口，价格确实低。低在哪里，得说清楚。

**没有 CN2 GIA 专线。** 洛杉矶机房走的是普通 BGP 优化线路，197ms 是国内平均延迟，不是专线级别的 140ms 上下。对延迟极度敏感的场景，比如实时协作、打游戏加速，普通 BGP 会在晚高峰给你脸色看。

**电信晚高峰会抖。** 这是普通 BGP 线路的通病，不是 RackNerd 独有。联通和移动用户体感会好一些。

**限量套餐真的会售罄。** $10.60 和 $18.66 这两档是社区渠道的特价库存，点进去显示缺货是常态。看到有货别犹豫，犹豫的下场就是回来买 $21.99。

**换 IP 有窗口期。** 购买后 **72 小时内**可以在控制面板点 “Change IP” 免费更换一次，超过 72 小时每次收 **$3**。下单后第一件事就是测 IP 通不通，别拖过三天再发现被墙。

**IPv6 要发工单。** 不是面板上点一下就有，得提交工单等官方手动配置。

把这些写在推荐前面，是因为它们都会真实影响使用。能接受，这台机器就是同价位里很划算的选择；不能接受，早点换方向比买完再后悔强。

## 哪些人不必买这台

**要极致国内延迟的。** CMIN2、CN2 GIA、AS9929 这类三网优化线路才是答案。洛杉矶做这类线路的商家里，ZgoCloud 的 CMIN2 特价 1 核 1GB 是 $35/年起，Ryzen9 7950X 配 CN2 GIA + 9929 + CMIN2 三网优化的 1 核 1GB 是 $66/年。价格是 RackNerd 的三倍，换来的是晚高峰更稳的回国路由。值不值，看你对延迟的容忍度。

**只需要一台临时测试机的。** 按小时计费的商家更省钱，用完就关，不用为一整年买单。
